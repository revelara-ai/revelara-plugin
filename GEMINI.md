# Revelara

The `revelara` MCP server gives you reliability evidence: production incidents, the user's risk register, a reliability controls catalog, distilled SRE knowledge, a service catalog, and a knowledge graph that links them. All results are scoped to the user's organization.

Use these tools when a task needs reliability judgment: the risk of a change, an incident investigation, a choice of controls, the failure patterns of a service or technology, or a reliability review of code or a design. Ground reliability claims in this evidence, not in general knowledge.

If a tool call fails with an authentication error, tell the user to authenticate the `revelara` MCP server. For first-time setup, follow `skills/setup/SKILL.md`.
